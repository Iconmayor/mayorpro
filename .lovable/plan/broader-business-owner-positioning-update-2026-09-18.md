# Broader Business-Owner Positioning Update

## Goal
Broaden Able Digital from an exclusively home-service message to a business-growth partner for local and service-led companies, while preserving its established home-service expertise, every existing project, and the current design.

## Changes

1. **Broaden site-wide positioning**
   - Update homepage, About, Services, Contact, footer, FAQs, and page metadata so business owners across sectors can see a fit.
   - Keep roofing, HVAC, plumbing, construction, landscaping, and related expertise visible as a strong specialization rather than the only audience.

2. **Expand the visible portfolio without inventing work**
   - Keep all six existing home-service case studies unchanged in the portfolio.
   - Surface the six existing general digital projects already present in project data.
   - Label the two groups clearly as **Case Studies** and **Selected Digital Projects**.
   - Use only existing project-type categories such as Web Development, Marketing, Automation, Design, and SEO; do not imply automotive, real-estate, finance, or education projects that are not in the data.
   - Use “Concept Project” or “Industry Demo” where the existing project information does not establish a real client engagement.

3. **Use evidence-safe language**
   - Preserve metrics already attached to existing project records, but do not add any new results, clients, statistics, testimonials, or claims.
   - Replace exclusive wording with language about business objectives, visibility, enquiries, conversion, credibility, and digital presence.

4. **Broaden calls to action**
   - Replace narrow home-service prompts with context-appropriate actions such as “Start Your Project,” “Grow Your Business,” and “Build Your Digital Presence.”

5. **Verify the finished experience**
   - Check desktop and mobile views as a roofing, automotive, and real-estate business owner.
   - Confirm all projects remain visible, links and theme controls still work, and the current visual system is unchanged.
   - Check the latest automated build result and fix any errors.

## Technical details
- Update existing React copy/data only; no layout redesign, navigation restructure, backend, or new dependencies.
- Reuse current Material UI, Tailwind, animation, and theme patterns.
- Update app-specific SEO and social metadata to match the broader positioning.
- Repository publishing is managed by Lovable; no manual Git state changes will be made.
